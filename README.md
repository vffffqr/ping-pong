# Онлайн Пінг-Понг

> Це шаблон для створення власної онлайн-гри **Пінг-Понг** на двох гравців. Гра вже працює через локальну мережу — залишилось зробити її красивою! 

## 🔧 Що вже зроблено:

- ✅ Готовий сервер і клієнт (гравець)
- ✅ Фізика м’яча та платформи
- ✅ Перемога при рахунку 10
- ✅ Очікування другого гравця
- ✅ Події зіткнення (для звуків)

## Як запустити проєкт

1. **Завантаж проєкт**
   - Можеш клонувати або завантажити ZIP:
     ```
     git clone https://github.com/KravaAO/ping-pong.git
     ```

2. **Увімкни сервер**
   - Відкрий `server.py` і запусти його:
     ```
     python server.py
     ```

3. **Запусти клієнта (2 рази)**
   - Відкрий два вікна (на одному або різних комп’ютерах з допомогою викладача) і запусти `client.py`:
     ```
     python client.py
     ```

> ⚠️ Усі файли мають бути у тій самій папці. Сервер запускається **лише один раз**, а `client.py` — для кожного гравця.

---

## 🖼️ Нові можливості (графіка, меню, магазин)

- Додано папку `assets/` з текстурами та звуками. Якщо файлів немає, то вони будуть згенеровані автоматично за допомогою `assets/generate_assets.py`.
- Головне меню з кнопками **Грати**, **Налаштування**, **Магазин скінів**, **Вихід**.
- Екран **Налаштувань**: введення імені гравця, регулювання гучності.
- **Магазин скінів**: вибір скінів для м’яча та платформи (збереження у `config.json`).
- Звукові ефекти: `click.wav`, `wall_hit.wav`, `platform_hit.wav`.

### Додавання власних скінів
- Коли ви додасте файли у папку `assets/` (наприклад `ball_skin_3.png`), перезапустіть `client.py` і вони будуть доступні у магазині (поки що автоматично відображаються дві опції — можна розширити код для динамічної підвантаження).

---

## Поради
- Щоб згенерувати або відновити ассети вручну, можна виконати:
```bash
python assets/generate_assets.py
```

- Налаштування зберігаються у `config.json` у корені проєкту.

## Як це працює?

### Сервер (`server.py`)
- Очікує **двох гравців**
- Веде гру: рухає м’яч, перевіряє зіткнення, надсилає **стан гри**
- Приймає команди `UP`, `DOWN` від гравців

### Клієнт (`client.py`)
- Підключається до сервера 
- Відображає гру, платформи, м’яч, рахунок
- Відправляє натискання клавіш (`W` / `S`) на сервер
